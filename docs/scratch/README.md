This folder is an **ephemeral scratchpad** for temporary artifacts produced during design/implementation work.

Examples of what belongs here:
- Investigation notes (e.g., `understand-*.md`)
- Implementation plans (e.g., `*.plan.md`)
- Session handoffs (e.g., `*.handoff.md`)
- Deep dives / option exploration (e.g., `deep-dive-*.md`)

Expectations:
- Files here may be incomplete, exploratory, or quickly outdated.
- After a task ships, integrate any long-lived truth into stable documentation (e.g., architecture notes, runbooks),
  then delete superseded scratch files.
